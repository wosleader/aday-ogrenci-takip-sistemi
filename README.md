# Aday Öğrenci Takip Sistemi

Bu klasör, Aday Öğrenci Takip Sistemi CRM projesi için başlangıç klasör yapısını ve proje tanıtım dokümanını içerir.

Ana doküman:

- `PROJE_TANITIMI_VE_MVP_PLANI.md`

Klasörler:

- `docs/`: teknik ve ürün dokümanları
- `src/`: uygulama kaynak kodları
- `src/features/`: modül bazlı ekranlar ve iş mantıkları
- `src/db/`: IndexedDB / Dexie veri katmanı
- `src/utils/`: ortak yardımcı fonksiyonlar
- `src/styles/`: stil dosyaları
- `public/`: PWA public dosyaları
- `tests/`: test dosyaları
- `backups/`: yerel yedek örnekleri
- `scripts/`: yardımcı scriptler
