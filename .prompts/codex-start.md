# Codex Start Prompt

Önce mevcut durumu kontrol et:
- git branch
- git status
- git log --oneline --decorate -10

Önce oku:
- docs/PROJECT_MEMORY.md
- docs/FILE_MAP.md
- docs/DECISIONS.md

Sadece bu işle ilgili checkpoint gerekiyorsa oku.
Tüm checkpoint dosyalarını gereksiz yere okuma.
Checkpoint Okuma Rehberi’ne göre sadece ilgili checkpoint’i oku.

PROJECT_MEMORY kısa özet, DECISIONS detaylı karar günlüğü olarak kullanılmalı; aynı kararı iki dosyada tekrar tekrar okumaya çalışma.

Kurallar:
- Kod yazmadan önce mevcut durumu özetle.
- Dosya bazlı plan çıkar.
- Onay almadan dosya değiştirme.
- Yeni paket kurma.
- Commit atma.
- Push yapma.
- Kapsam dışına çıkma.

- Aktif branch
- Son commit
- Mevcut durum özeti
- İlgili dosyalar
- Teknik plan
